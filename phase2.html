How to use

  1. Tap the big green microphone.
  2. If Chrome asks to use the microphone, tap Allow.
  3. Speak. Your words appear in the box.
  4. Tap the microphone again to stop (or just pause and it stops itself).
  5. You can fix the text by tapping the box, then press Send.

Microphone permission

Chrome asks once. If you tapped Block by mistake: Chrome menu (three dots) → Settings → Site settings → Microphone → allow this page. Also check Android Settings → Apps → Chrome → Permissions → Microphone.

Voice recognition needs internet

Chrome on Android sends your voice to Google to turn it into text, so it does not work offline. All poker calculations in later phases will work offline.

If the microphone does not work

  • Open the file in Chrome, not inside TrebEdit's preview (the preview cannot do speech recognition).
  • Use the keyboard's own microphone key (Gboard) inside the text box. It does the same job, and it works everywhere.
  • Or simply type your message and press Send.

Voice commands

In this first phase the assistant only repeats what it heard. Two commands already work: say "stop talking" and "repeat that". Poker commands arrive in Phase 2.

Learning tool only

This app is for practice, learning and reviewing hands you have already played. Do not use it for live decisions in real-money games where outside assistance is not allowed.
